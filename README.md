# Arduino Projects

A collection of electronics, microcontroller, and embedded programming projects developed using Arduino.

## About

This repository documents my practical experience with Arduino-based systems, electronic components, sensors, and hardware-software integration.

It includes projects developed during high school and personal experimentation, focusing on automation, measurement systems, and embedded programming.

## Projects

### 1. Smart Automated Bin
An automated waste bin developed using Arduino and electronic components.

The system uses sensor-based detection to automate the opening mechanism.

### 2. Digital Temperature Monitoring
A digital temperature monitoring system using an Arduino board and a temperature sensor.

The project focuses on sensor integration, temperature measurement, and displaying measurement results.

### 3. Automated Pendulum Measurement
An experimental measurement system designed to investigate pendulum motion.

The project involves electronic components and automated measurements to determine oscillation-related parameters.
